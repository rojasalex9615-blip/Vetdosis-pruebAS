# VetDosis Pro — sitio público

Sitio público independiente del cliente Flutter. Esta carpeta no altera la aplicación móvil ni las ramas de cierre de beta.

## Desarrollo
```bash
cd site
npm install
npm run dev
```

## Compilación
```bash
npm run build
npm run preview
```

## Antes de publicar
- Confirmar dominio y URLs de la aplicación.
- Conectar las rutas reales de acceso y registro.
- Verificar qué módulos están disponibles y cuáles siguen en desarrollo.
- Confirmar precios, términos, privacidad y contacto.
- Probar diseño responsivo, accesibilidad, SEO y enlaces.

Los planes y funcionalidades de esta primera versión son informativos; no constituyen una oferta comercial ni certifican disponibilidad funcional.
